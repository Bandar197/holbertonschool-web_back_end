# Python - Async Comprehension

This project demonstrates asynchronous generators,
asynchronous comprehensions, and concurrent execution
using Python asyncio.

## Tasks

### Task 0 - Async Generator
Generate ten random numbers between 0 and 10.
Wait asynchronously for one second before yielding
each number.

### Task 1 - Async Comprehensions
Collect ten random numbers into a list using
an asynchronous comprehension.

### Task 2 - Measure Runtime
Execute four asynchronous comprehensions concurrently
using asyncio.gather and measure the total runtime.

## Concepts
- Asynchronous generators
- Async and await
- Async comprehensions
- asyncio.sleep
- asyncio.gather
- Type annotations
- Runtime measurement

## Python Version
Python 3.8
